NODO COMUNITARIO AGRELO — PRESENTACIÓN WEB

Cómo abrir
1. Descomprimir la carpeta.
2. Hacer doble clic en index.html.
3. Funciona sin internet en Chrome, Edge, Firefox y Safari.

Contenido
- index.html: estructura del sitio.
- styles.css: diseño visual y adaptación móvil.
- script.js: navegación, visor de láminas, acordeones y ampliación de imágenes.
- assets/: imágenes extraídas de las láminas originales.

Qué conviene completar
Buscar en index.html las frases:
- "Tesis de Arquitectura · Mendoza · 2026"
- "Proyecto de tesis · Arquitectura"
y reemplazarlas por nombre de tesista, facultad, universidad, director/a, cátedra y año.

Publicación
La carpeta puede subirse tal cual a GitHub Pages, Netlify, Vercel o cualquier hosting estático.

Criterio
La web conserva la identidad visual de las láminas: bordó, arena, blanco y tonos tierra, y reorganiza el material como una narración digital para la defensa de tesis.
